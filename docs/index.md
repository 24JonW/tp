**ShutterLink is a desktop application for managing photography client engagements.** It stores contact details,
event information, and engagement stages. While it has a GUI, most user interactions happen through a CLI
(Command Line Interface).

* If you are interested in using ShutterLink, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing ShutterLink, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
